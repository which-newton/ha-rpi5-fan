## Personal hub maintenance

Read [docs/HUB-MAINTENANCE.md](docs/HUB-MAINTENANCE.md) before completing work that
changes this project's purpose, status, user-facing behaviour, tools, destinations
or documentation links. Updating the relevant `tpdowns-hub/projects.json` entry
or hosted page is part of that change, not a separate optional task. Preserve
the hub shell and project ownership; source ownership does not decide which
project a tool belongs to. Every PR needs a `Hub-Impact` assessment and concrete
`Hub-Reason`; use `Hub-PR` for the companion hub change. Follow existing release
authorization, and report prepared, merged, deployed and live-verified separately.
